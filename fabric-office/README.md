# 🧵 نظام مكتب القماش

نظام بسيط ومتكامل لإدارة مكتب/محل القماش، شغال من المتصفح مباشرة بدون أي تسطيب أو إنترنت.

## طريقة التشغيل
افتح ملف `index.html` بأي متصفح (Chrome أو Edge)، أو من الرابط المنشور على GitHub Pages:
`https://m-7assann.github.io/filterable-product-list/fabric-office/`

## المميزات
- **الأقمشة والمخزن**: كود، اسم، نوع، لون، وحدة (متر/ياردة/كيلو/ثوب)، سعر شراء وبيع، حد تنبيه، مع بحث وفلترة بالنوع وتنبيه للأصناف القليلة.
- **فواتير البيع**: لعميل مسجل (آجل أو جزء مدفوع) أو عميل نقدي، خصم، طباعة الفاتورة، والمخزن يتخصم تلقائياً ومش بيسمح تبيع أكتر من المتاح.
- **فواتير الشراء**: من الموردين، المخزن يزيد تلقائياً وسعر الشراء يتحدث بآخر سعر.
- **العملاء والموردين**: رصيد افتتاحي، رصيد لحظي، وكشف حساب كامل قابل للطباعة.
- **التحصيل والسداد**: تسجيل الدفعات من العملاء وللموردين.
- **المصروفات**: إيجار، مرتبات، كهرباء، نقل... إلخ.
- **التقارير**: المبيعات، تكلفة البضاعة، مجمل وصافي الربح، النقدية الداخلة والخارجة، الأصناف الأكثر مبيعاً، المبيعات حسب العميل.
- **النسخ الاحتياطي**: تحميل نسخة من البيانات واسترجاعها على أي جهاز.

## ملاحظة مهمة عن البيانات
البيانات بتتحفظ داخل المتصفح على نفس الجهاز. اعمل **نسخة احتياطية** من شاشة الإعدادات بشكل دوري.
