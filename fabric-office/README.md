# 🧵 نظام مكتب القماش

نظام لإدارة مكتب قماش **بيبيع بالتوب**. كل توب ليه رقم وطول، وسعره = سعر المتر × طول التوب.
بيشتغل من المتصفح على الكمبيوتر أو الموبايل.

## طريقة التشغيل
- **على جهاز واحد (من غير إنترنت):** افتح `index.html` بـ Chrome أو Edge.
- **أونلاين على أكتر من جهاز وبحسابات للموظفين:** اتبع الخطوات في [SETUP_ONLINE.md](SETUP_ONLINE.md).
- **على الموبايل كتطبيق:** افتح الرابط من Chrome، ومن القائمة ⋮ اختار **"إضافة إلى الشاشة الرئيسية"**.

## المميزات
- **الأقمشة والتوبات:** كل صنف ليه سعر متر للبيع والشراء، وكل توب متسجل برقمه وطوله. بتعرف عندك كام توب وكام متر من كل صنف، وفيه تنبيه لما التوبات تقل، وبحث برقم التوب.
- **فواتير البيع:** بتختار التوبات بالظبط، بالضغط عليها أو بكتابة رقم التوب. الإجمالي بيتحسب لوحده من أطوال التوبات، والتوب اللي اتباع مبيظهرش تاني.
- **فواتير الشراء:** بتسجل التوبات الجديدة (رقم + طول)، ولو كذا توب بنفس الطول تضيفهم مرة واحدة. حساب المورد وسعر الشراء بيتحدثوا لوحدهم.
- **واتساب:** تبعت الفاتورة بتفاصيل التوبات، وكشف الحساب والتذكير بالرصيد، وإيصال استلام الفلوس.
- **العملاء والموردين:** رصيد أول بأول، وكشف حساب كامل تقدر تطبعه.
- **التحصيل والسداد والمصروفات.**
- **التقارير:** المبيعات بعدد التوبات والأمتار، وتكلفة التوبات المباعة، والمكسب قبل وبعد المصروفات، والفلوس اللي دخلت وطلعت، وأكتر الأصناف والعملاء.
- **حسابات للموظفين:** في الوضع الأونلاين، بصلاحيات تحددها انت لكل موظف.
- **طباعة** الفواتير وكشوف الحساب والتقارير.
- **نسخ احتياطي** واسترجاع.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `js/config.js` | بيانات الربط بـ Firebase (اختياري) |
| `js/store.js` | البيانات والحسابات (المخزن، الفواتير، الأرصدة) |
| `js/backend.js` | الحفظ على الجهاز أو أونلاين، والحسابات والصلاحيات |
| `js/app-core.js` | التنقل وشاشة الدخول والرئيسية |
| `js/views-*.js` | باقي الشاشات |
| `firestore.rules` | قواعد حماية البيانات الأونلاين |
