# صفحة التصويت في ملف واحد

`index.html` هنا هو صفحة تصويت العملاء على الرسومات، بكل حاجتها في ملف واحد.
ارفعه في repo جديد لوحده على GitHub وشغّل GitHub Pages، فيبقى ليك رابط منفصل زي:
`https://fathyemad22-ops.github.io/rasomat/`

بعدها حط الرابط ده في السيستم: الإعدادات ← "رابط صفحة التصويت".

لو اتغير أي حاجة في صفحة التصويت أو في بيانات Firebase، اعمل الملف من جديد:
```
python3 build.py
```
